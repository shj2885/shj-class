오늘 한 문장 — 클로드에게 맡기면 아마추어, 세팅을 알려 주면 프로가 됩니다.

1 · 모션그래픽 도구 지도

예전엔 무엇으로 만들었고, 지금은 무엇이 바뀌었나.

도구하던 일어려웠던 점
애프터이펙트 (Adobe)모션그래픽 표준. 레이어 + 키프레임유료 구독, 방대한 메뉴, 긴 학습
시네마 4D · 블렌더3D 모션 (블렌더는 무료)3D 개념, 긴 렌더
프리미어 · 파이널컷 · 다빈치 리졸브영상 편집(컷·자막·소리)모션 전용은 아님
애플 Motion맥용 모션 프로그램맥 전용
로티 · 리브움직임을 앱·웹에 넣는 형식만들 땐 디자인 툴 필요
젯터 · 캔바웹 템플릿으로 빠르게템플릿 안에서만, 다들 비슷
코드 (CSS · GSAP · Three.js) · 리모션코드로 움직임·영상코딩을 해야 했다
지금: 클로드 + HyperFrames코드는 클로드가 쓰고, 녹화기가 영상으로세팅값을 정하는 것이 실력

프로가 정하는 공통 개념 세 가지 — 레이어(겹쳐 쌓기) · 키프레임(언제 어디에) · 이징(속도의 곡선)

2 · 클로드 모션그래픽 3층 구조

클로드는 그림을 그리지 않습니다. 움직이는 웹 페이지를 씁니다.

  1. 쓰는 손 — 클로드: 글자·색·움직임을 코드로
  2. 움직임 — 웹 페이지 + GSAP·Three.js 같은 움직임 도구: 브라우저가 재생
  3. 녹화기 — HyperFrames가 1초에 30장씩 찍고, FFmpeg가 mp4로 묶고 소리를 붙임

프롬프트 1 · 첫 모션 (Lv1)

claude.ai 대화창에서 바로. 채울 칸이 없습니다.

"11월 원데이 클래스"라는 글자가 한 글자씩 튀어나오는 5초짜리 모션을 웹 페이지로 만들어 줘.
세로 9:16, 화면에서 바로 재생되게.

미리보기에서 글자가 움직이면 Lv1 달성 · 대화창으로는 mp4 저장·내 글꼴·규칙 저장이 어렵다 → 3으로

3 · 기본 세팅 체크리스트

"모션그래픽 만들어 줘"만 해도 클로드가 알아서 깔 때가 있어요. 그런데 무엇이 깔렸는지 모르면 결과가 이상할 때 고칠 곳을 모릅니다. 하나씩 알고 갑니다. 클로드 코드(유료 플랜)에서 진행합니다.

순서세팅하는 일확인
0작업 폴더 motion-class영문·띄어쓰기 없이. 클로드 앱 Code 화면에서 연결☐
1Node.js (LTS)엔진. HyperFrames를 돌리는 바탕☐
2FFmpeg장면을 mp4로 묶고 소리를 붙임☐
3Git (윈도우)윈도우에서 클로드 코드가 명령 실행에 사용☐
4HyperFrames 프로젝트녹화기 + 도구 규칙 + 버전 고정☐
5스킬전문가의 일하는 순서☐
6재료 폴더assets/fonts · images · audio · renders☐

프롬프트 2 · 내 컴퓨터 점검

모션그래픽 영상을 만들 준비를 하려고 해. 아직 아무것도 설치하지 말고,
이 컴퓨터에 Node.js, FFmpeg, Git이 있는지와 각각 버전을 확인해서 표로 보여 줘.
없는 것은 무엇에 쓰는 프로그램인지 한 줄씩 설명해 줘.

프롬프트 3 · 필요한 것만 설치

방금 표에서 없는 것만 설치해 줘. 설치하기 전에 무엇을 어디서 받는지 한 줄씩 말해 주고,
끝나면 다시 버전을 확인해서 표로 보여 줘.

프롬프트 4 · HyperFrames 프로젝트로 시작 + 3초 영상

이 폴더를 HyperFrames(https://github.com/heygen-com/hyperframes) 프로젝트로 시작해 줘.
init으로 만들고, 버전을 고정해 줘. 만들어진 파일이 각각 무슨 역할인지 한 줄씩 알려 줘.
그다음 흰 바탕에 검정 원이 왼쪽에서 오른쪽으로 움직이는 3초짜리 1080×1920 영상을 렌더해 줘.

스킬 ① HyperFrames 설치 (공식 안내)

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

또는 npx skills add heygen-com/hyperframes → 고르는 화면에서 Core Skills만. 최신화 npx hyperframes skills update

4 · 모션그래픽 용어 21 + 프로 세팅 파일

모션그래픽 용어 21

"좋은 느낌으로" 대신 이름으로 말하세요. 적극 조합해서 "~해 줘"로 끝내면 됩니다.

#용어뜻

프롬프트 6 · 내 규칙 저장하기

규칙을 한 번 말해 주고, 저장해 달라고 하면 끝. 저장된 규칙은 그 폴더에서 클로드가 매번 먼저 읽는 지침이 됩니다.

앞으로 이 폴더에서 만드는 영상은 이 규칙을 지켜 줘.

[세로 릴스 크기], 글자는 크게 1.5초 이상, 색은 지정색이 없는경우 내용에 맞게 선택해

단  보라색 그라데이션은 금지.

이 규칙을 CLAUDE.md에 저장해 줘.

더 자세한 버전 (심화단계)

이 폴더의 CLAUDE.md에 모션그래픽 작업 규칙을 만들어 줘. 앞으로 이 폴더의 모든 영상은 이 규칙을 지켜.

- 해상도 [가로×세로], [프레임]fps, 기본 길이 [초], 장면 [개수]
- 글꼴: assets/fonts 안의 파일만 사용, 제목은 가장 굵게
- 색: 배경 [색], 글자 [색], 강조 [색]
- 이징: 들어올 때 감속, 나갈 때 가속. 같은 속도로 움직이는 것 금지
- 글자는 최소 1.5초 보이게
- 안전 영역: 위 15%, 아래 20%에는 글자를 두지 않음
- 쓸 움직임: [용어 21에서 고르기]
- 금지: 모든 장면 같은 페이드, 의미 없는 모서리 라벨, 보라색 그라데이션, 반복 효과음, 내가 주지 않은 숫자·후기
- 렌더: 렌더 전에 꼭 검사(check)를 돌리고 문제가 없을 때만 renders 폴더에 mp4. 버전은 고정된 것만 사용

지금 있는 CLAUDE.md의 HyperFrames 규칙은 지우지 말고, 그 아래에 '내 디자인 규칙'으로 붙여 줘.
다 쓰면 규칙을 다섯 줄로 요약해 줘.

npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"

5 · 같은 한 줄, 다른 결과

빈 폴더(A)와 세팅한 폴더(B)에 한 글자도 다르지 않은 같은 문장을 넣었습니다. 달라진 건 세팅 하나입니다.

비교 영상(A · B · B+ · 효과음 비교)은 강의 중 화면으로 보여 드리고, 강의 후 노션 원본 페이지에 올립니다.

프롬프트 10·11 · 음악과 비트

이 영상에 어울리는, 상업적으로 써도 되는 무료 음악을 3개 찾아 줘. 라이선스 조건도 같이 알려 줘.
고른 음악 파일([파일 이름])을 넣고, 비트에 맞춰 장면 전환을 다시 맞춰서 렌더해 줘.

음악을 직접 만들고 싶다면

클로드 코드가 코드로 소리를 계산해서 배경음 파일을 만들어요. 직접 만든 소리라 저작권 걱정이 없고, 장면 전환에 박자를 정확히 맞출 수 있어요. 오늘 본 인트로 · 3층 구조 영상의 배경음도 이렇게 만들었어요.

이 영상에 어울리는 배경음을 코드로 직접 만들어 줘.
밝고 가벼운 분위기, 100BPM, 영상 길이에 맞춰서.
장면이 바뀌는 시점에 맞춰 악기가 하나씩 더해지게 하고, 끝은 서서히 작아지게.

마림바 · 패드 · 킥처럼 단순하고 깔끔한 배경음까지가 잘 되는 범위예요. 노래(보컬)는 어려워요. 들어 보고 "더 밝게", "더 차분하게", "피아노 느낌으로"처럼 고쳐 달라고 하세요.
