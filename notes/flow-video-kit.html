flow.google.com → 구글 계정 로그인 → 새 프로젝트 → 왼쪽 위 날짜 제목을 눌러 이름 바꾸기 → 왼쪽 도구 → 위쪽 템플릿 탭

오늘 쓰는 건 두 개 — Storyboard Studio · Shot Explorer

2 · 스토리보드 스튜디오 — 시놉시스 한 번으로 장면 8장

순서

  1. 시작 창에서 화풍 고르기 — 오늘은 말랑한 애니메이션 느낌의 3D-Animation (실사는 Realistic, 점토 인형은 Claymation, 그림책 느낌은 Create custom style에 Soft Watercolor Storybook) → Get Started
  2. 1. Script — 아래 입력칸(Describe the story…)에 프롬프트 1 붙여넣기 → 대본이 길게 나와도 읽지 않아도 됩니다
  3. 2. Assets — 인물·장소·소품이 나오면 Autofill 한 번 → 주인공이 한 캐릭터로 고정됐는지 확인
  4. 3. Storyboard — Autofill Scene → 장면 그림 8장

프롬프트 1 · 시놉시스

① 예시 — 가을 오후, 은행잎 공원의 아기 강아지

따뜻한 가을 오후, 노란 은행잎이 가득 깔린 공원 잔디밭에서 아기 웰시코기 한 마리가 신나게 노는 60초짜리 귀엽고 따뜻한 영상을 만들고 싶어.
사건을 설명하는 영상이 아니라 잔잔한 음악에 맞춰 흘러가는 영상이야. 줄거리 말고 장면과 분위기로, 대사 없이 써줘.

등장인물은 아기 웰시코기 한 마리뿐이야. 동글동글한 몸, 크고 반짝이는 눈, 짧은 다리, 폭신한 엉덩이, 목에 작은 빨간 스카프.
강아지는 사람처럼 행동하지 않고, 진짜 강아지처럼 뛰고 냄새 맡고 뒹굴고 꼬리를 흔들어.
장소는 한 곳뿐이야. 큰 은행나무 한 그루가 있는 넓은 공원 잔디밭. 바닥엔 노란 은행잎이 수북하고, 멀리 나무 벤치 하나.
시간이 흐르지 않게 해줘. 처음부터 끝까지 같은 날 같은 오후, 같은 따뜻한 금빛 햇살.

장면은 여덟 개로 나눠줘.
1. 멀리서 본 큰 은행나무와 노란 잎 위의 작은 강아지
2. 수북한 낙엽 더미로 폴짝 뛰어드는 강아지
3. 낙엽 속에서 얼굴만 쏙 내민 강아지 클로즈업
4. 바람에 날리는 은행잎을 쫓아 달리는 강아지, 옆에서 본 모습
5. 위에서 내려다본, 낙엽 위에 배를 보이고 누워 뒹구는 강아지
6. 꼬리를 흔들며 은행나무 쪽으로 걸어가는 뒷모습
7. 강아지 코끝에 살포시 내려앉은 은행잎 하나, 아주 가까이
8. 햇살 아래 낙엽 위에서 동그랗게 잠든 강아지, 바람에 잎이 살랑 흩날림

사람은 나오지 않게 해줘. 글자, 간판, 상표는 어디에도 나오지 않게 해줘.
무섭거나 슬픈 분위기, 다치는 장면은 넣지 마.

② 내 가게용 — [대괄호]만 바꾸세요

[날씨·시간], [내 가게 한 줄 소개]에서 [주인공]이 [하는 일]을 하는 60초짜리 짧은 영상을 만들고 싶어.
사건을 설명하는 영상이 아니라 잔잔한 음악에 맞춰 흘러가는 영상이야. 줄거리 말고 장면과 분위기로, 대사 없이 써줘.

등장인물은 한 명뿐이야. [주인공 — 사람이면 나이·머리·옷, 동물 캐릭터면 동물·옷·작은 특징 하나].
장소는 한 곳뿐이야. [장소 모습 — 창, 가구, 진열된 것 두세 가지].
시간이 흐르지 않게 해줘. 처음부터 끝까지 같은 날 같은 시간, 같은 빛.

장면은 여덟 개로 나눠줘. 멀리서 본 전체, 손 클로즈업, 위에서 본 모습, 뒷모습, 상품 클로즈업을 골고루 섞어서.

글자, 간판, 상표, 포장의 글씨는 어디에도 나오지 않게 해줘.
다치거나 아픈 장면은 넣지 마.

바꿔 넣기 예시 — 이른 아침, 동네 작은 빵집에서 제빵사가 첫 빵을 꺼내는 / 맑은 오후, 작은 꽃집에서 플로리스트가 꽃다발을 묶는 / 봄 꽃밭에서 아기 고양이가 나비를 쫓는

동물 주인공 팁 — 동물에게 사람 일을 시키지 말고 뛰기·뒹굴기·잠자기처럼 원래 하는 행동만 시키면 귀엽게 나옵니다.

다듬기 — 같은 입력칸에 이어서

장면을 위의 여덟 개로 정확히 나눠줘.
조금 더 잔잔하고 조용한 분위기로 다시 써줘. 인물과 장소는 그대로.

확인 — 주인공이 한 캐릭터로 고정됐나 · 장면이 8장인가 · 화면에 글자·간판이 없나

그림이 아예 안 만들어지는 장면이 있습니다. 누가 다치거나 아픈 장면, 병원 장면은 막혀 있어요. 고장이 아니라 안전장치입니다. 그 장면만 순한 내용으로 바꾸세요.

3 · 샷 익스플로러 — 사진 한 장을 다른 각도로, 더 넓게

촬영으로 치면 카메라를 옮기는 일입니다. 같은 캐릭터·같은 장소는 그대로, 보는 자리만 바뀝니다.

도구 → 템플릿 → Shot Explorer → SELECT IMAGE 로 장면 그림 고르기 → 아래 버튼 하나 누르기

줄버튼하는 일쓰는 곳
Perspectiveoverhead · side · back위에서 · 옆에서 · 뒤에서주인공을 위에서 · 뒷모습
Panleft · right · up · down화면 밖을 이어 그려 넓히기세로 쇼츠 위아래 여백
Zoomzoom in · zoom out · extreme detail가까이 · 멀리 · 아주 가까이얼굴 · 상품 클로즈업
Fast · Pro빠르게 · 더 정교하게연습 Fast · 최종 Pro

이번 예시에서 뽑는 네 장

  1. 장면 1(은행나무 전체) → zoom in — 다음 단계 '끝 그림'으로 씁니다
  2. 장면 2(낙엽 뛰어들기) → overhead — 위에서 본 모습
  3. 장면 3(얼굴 쏙) → extreme detail — 아주 가까이
  4. 장면 6(뒷모습) → Pan up — 세로 화면용으로 은행나무 위쪽까지 넓히기

결과가 어색하면 RESET 후 다시 · surprise me 는 재미로 한 번

4 · 그림을 영상으로 — 8초씩

프로젝트 화면 아래 입력창 — 시작 칸에 그림 한 장(두 장이면 종료 칸에도) → 아래 상자를 붙여넣고 → 만들기 · 동영상 8초

프롬프트 2 · 그림 한 장으로

첫 줄만 장면에 맞게 바꾸고, 둘째 줄은 늘 붙입니다. 음악은 Vids에서 따로 깔기 때문에 영상에는 넣지 않아요.

강아지가 낙엽 더미로 폴짝 뛰어들자 노란 잎이 사방으로 흩날린다.
말소리, 음악, 자막은 넣지 마. 바람과 낙엽 소리만 아주 작게.
장면첫 줄 바꿔 넣기
은행나무 전체바람이 불어 노란 은행잎이 천천히 흩날리고, 카메라가 아주 천천히 다가간다.
얼굴 쏙낙엽 속에서 강아지가 고개를 쏙 내밀고 귀를 쫑긋 움직인다.
잎 쫓기바람에 날리는 은행잎을 강아지가 짧은 다리로 통통 쫓아 달린다.
뒹굴기낙엽 위에서 강아지가 배를 보이고 좌우로 뒹군다. 잎이 살짝 들썩인다.
뒷모습꼬리와 엉덩이를 씰룩이며 은행나무 쪽으로 걸어간다.
잠든 모습잠든 강아지의 배가 천천히 오르내리고, 잎이 바람에 살랑 내려앉는다.

프롬프트 3 · 시작·끝 두 장 = 카메라가 다가간다

시작 칸: 장면 1(은행나무 전체) · 종료 칸: 샷 익스플로러에서 만든 zoom in 그림

카메라가 금빛 은행나무 아래로 천천히 다가가 노란 잎 위의 아기 강아지에게 멈춘다. 한 번에 이어지는 부드러운 움직임.
말소리, 음악, 자막은 넣지 마. 바람과 낙엽 소리만 아주 작게.

프롬프트 4 · 세로 쇼츠용

시작 칸: 샷 익스플로러에서 Pan up 으로 넓힌 그림

은행잎이 천천히 떨어지고, 카메라가 아래에서 위로 아주 천천히 올라가며 금빛 은행나무 꼭대기와 파란 하늘을 보여준다.
말소리, 음악, 자막은 넣지 마. 바람 소리만 아주 작게.

확인 — 영상 중간에 얼굴이 바뀌지 않았나 · 화면에 글자가 생기지 않았나 · 말소리·음악이 섞이지 않았나

낙엽 · 바람 · 물 · 김 · 흔들리는 꼬리처럼 저절로 움직이는 것이 있는 그림이 잘 나옵니다.
